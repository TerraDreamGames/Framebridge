# Native advanced controls

Import `controls.framebridge.json` with the matching Framebridge plugin into a separate blank Studio place, then press Play. The generated trusted LocalScript runs eight advanced controls, panel/window actions, native tabs and a live Coins label. This example requires no artwork uploads or third-party runtime.

Place the optional `DemoControls.client.luau` inside the imported ScreenGui before Play to supply local demonstration data and show output attributes as labels. It is a custom example script, preserved by reimport. It does not grant currency, save progression, or award roulette rewards.

Try toggling, dragging the slider/window, opening/closing the window with a one-second cooldown, hovering or selecting the tooltip, switching tabs, unlocking the base skill then its dependent skill, and spinning the roulette control. Read the generated attributes in Explorer or your own LocalScripts. Your server owns real reward and skill authorization.

See [the configuration and runtime guide](../../docs/ADVANCED_CONTROLS.md) for limits, outputs and supported behavior.
