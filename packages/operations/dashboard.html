Metric definitions & sources

Traffic comes from Cloudflare’s Workers GraphQL Analytics API for this relay Worker only. It includes health checks and operator requests. Cloudflare may use adaptive sampling and reporting can lag. Worker exceptions are runtime failures, not every HTTP 4xx/5xx response.

Connections, uploads, quotas and storage come from the protected aggregate endpoint in the existing RelayRoom. Online means Studio authenticated within 90 seconds; it is not a WebSocket count or unique-user count. Presence writes are throttled to 30 seconds. Expired sessions are excluded. Saved pairings can outlast an open app.

SQLite size includes metadata and retained data. Artwork bytes come from tracked metadata, including pending/cleanup objects; they are not an R2 billing measurement. Uploaded Roblox images reside with Roblox, not in an S3 bucket. Quotas reset at midnight UTC. No names, IPs, images, tokens or transfer contents are returned.
