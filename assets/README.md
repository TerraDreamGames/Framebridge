# Artwork and design resources

Reusable artwork lives in this root folder. Use these files in Figma, documentation and other projects.

| Resource                                                              | Location                                               | Format          |
| --------------------------------------------------------------------- | ------------------------------------------------------ | --------------- |
| Bridge Monogram logo, master and compact                              | [brand](brand/README.md)                               | Transparent PNG |
| Class glyphs, interface glyphs, export-status icons and fallback icon | [glyphs](glyphs/README.md)                             | Standalone SVG  |
| Transparency checker tile                                             | [textures/checker.png](textures/checker.png)           | 24 × 24 PNG     |
| Inventory window, panels, buttons, slots and item artwork                | [examples/inventory](examples/inventory/README.md)      | Transparent PNG |
| Google Sans variable font                                             | [fonts/GoogleSans.woff2](fonts/GoogleSans.woff2)       | WOFF2           |
| Inter variable font                                                   | [fonts/InterVariable.woff2](fonts/InterVariable.woff2) | WOFF2           |

Glyphs include dark, light and monochrome variants, plus arranged vector sheets. Drag SVG or PNG files into Figma to reuse them. SVGs are editable vectors with resolved colors and require no React, fonts or external CSS.
