# Framebridge brand assets

The Bridge Monogram is an F-shaped bridge used in the plugin's toolbar, headers and welcome flow.

- `framebridge-mark.png` — transparent master PNG.
- `framebridge-mark-256.png` — compact PNG for interface use and uploads.

Keep the artwork's proportions and transparent background. Use the blue mark with the Framebridge wordmark on dark or light surfaces; leave clear space around it.

The Figma interface bundles the compact mark locally. Studio's `Brand` module uses the matching Roblox image asset. These are raster assets; no vector master is included.
