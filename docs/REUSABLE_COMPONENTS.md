# Reusable components

In the connected plugin, open **More options → Connection & export → Export reusable component** after analysis. The offline build labels the menu entry **Export options**. Use this optional section to download a standalone widget or Studio template.

Choose a reviewed group, or select a native layer in the preview/Explorer to extract that layer. Repeated suggestions compare exported properties, text, internal hierarchy, interactions and artwork. Root placement can differ. A linked Roblox image ID takes precedence over cached Figma artwork; unresolved images need equal actual bytes, not equal filenames. Different text or image links stay separate. Review is bounded to 15,000 layers, 100 source levels and 200 groups, with an additional hierarchy-comparison limit.

For a button state family, use one Figma component set with equal-sized variants. Name them `State=Default`, `State=Hover`, `State=Pressed`, `State=Disabled` and optionally `State=Selected`. A State field can appear anywhere in a comma-separated variant name; simple Default/Hover/etc. names work too. Default and at least one other state are required. Duplicate/unknown states, incompatible bounds and configured variant/set root interactions require correction before grouping. The extractor creates one transparent TextButton with editable native state visual children. Disabled follows Active/Interactable; Selected follows the `FramebridgeSelected` attribute; hover/press follow native input. Missing state visuals fall back to Default.

Each state visual retains its own artwork, captured text, theme and layout metadata; the transparent input wrapper carries only its input geometry. Descendant theme, particle, keyframe and motion owners that referred to the original variant button are redirected to that wrapper, while independent nested-button owners stay unchanged. A variant with nested state visuals driven by that same variant button cannot also be grouped as an outer state family. Extract the variant independently or remove its internal state configuration before grouping it; family review excludes that unsupported shape and extraction gives that guidance.

Enter a component name and choose the download:

- **Download widget module** includes `Design.luau` or `Design.tsx`, a framework-specific setup guide, image manifest, conversion notes and only the required unresolved PNGs. The module returns one GuiObject that belongs inside an existing UI collector/container. React Lua and roblox-ts use `Assets` and `RootProps`; Fusion 0.3 takes `(scope, assets, rootProps)`; vanilla Luau takes `(parent, assets, rootProps)`. The download documents installation and cleanup. Each mounted copy owns its runtime and state, even when IDs/artwork match.
- **Download Studio template** creates an independent `.framebridge.json` or ZIP for Framebridge’s Studio importer. It contains an editable ScreenGui and one component at its authored pixel size. Use Studio to position, constrain and edit the result. Template reimports preserve matching instance identity and custom scripts. Source modules are snapshots and do not participate in importer update tracking.

`RootProps` supports Name, Position, Size, AnchorPoint, Rotation, LayoutOrder, ZIndex, Visible, Active and Interactable. Root placement resets to top left; default Size uses the source bounds. Internal layout keeps the analysis conversion settings. Pick a suitable Size for the parent and test text/layout at your target resolutions. Framework copies can share image bindings without sharing runtime state. Destroy vanilla widgets, clean the Fusion scope or unmount React to release their listeners.

Extraction preserves interactions whose targets, state owners and motion owners/slots stay inside the chosen subtree. An external dependency is rejected clearly instead of being silently discarded. Include the complete dependency subtree or configure an independent component first. Suggestions exclude such roots. Extraction does not parameterize text/content slots, replace repeated widgets in the original design, create a live Figma component link, automatically install framework libraries or generate gameplay logic.
