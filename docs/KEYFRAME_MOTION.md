# Keyframe chains

Select a layer and expand **Keyframe timeline** in Properties. Enable a chain, choose a trigger, and record two or more poses. Each pose contains an X/Y offset in native pixels, uniform scale multiplier, rotation offset in degrees, and opacity multiplier. Easing belongs to the segment arriving at that frame. Linear, quadratic, cubic, sine and back easing support In, Out and In/out directions.

Choose a recorded frame to load it into the pose fields, edit the pose, then **Record pose** to replace it. Change **Record at seconds** to insert a new frame. Drag the small preview to record X/Y movement, or type exact values. Scrubbing samples the full chain, including repeats and return legs. **Play chain** starts from the first pose; **Stop** restores the preview. The preview uses a representative box and approximates transforms. **Test UI** also plays configured mount, visibility, action and state chains on the rendered layout. Neither preview executes game scripts or local Roblox attribute changes.

**Set layer reference** captures the current authored geometry. Edit the layer in Figma, Analyze again, and **Capture layer pose** records its position, rotation, uniform resize and opacity relative to that reference. The layer must keep the same parent and resize uniformly; reparenting and nonuniform resizing report a useful error. Fully transparent authored layers require manual opacity poses on a visible authored base. Resetting the reference retains the chain; **Use manual poses** resets the reference so their offsets are relative to the current authored layer. At export, recorded poses are rebased to the final native layer geometry. Earlier recorded poses therefore remain meaningful after subsequent design edits. The author reference is saved in document overrides and is never sent as runtime metadata.

All chain edits use the existing saved document settings and Undo/Redo history. Ordinary Roblox Properties remain the editor for imported UI; use the compact Figma timeline to configure runtime behavior.

| Trigger         | Native behavior                                                                                                                                                                                                        |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| On mount        | Plays once when its runtime mounts and the layer is visible.                                                                                                                                                           |
| When visible    | Plays on initial visibility and whenever the layer or its ancestor collector/panel becomes visible.                                                                                                                    |
| On activate     | Plays from a native button Activated event or the runtime activation API, alongside its configured panel/tab action.                                                                                                   |
| Hover / focus   | Enters on hover or selected focus and restores on exit.                                                                                                                                                                |
| Pressed         | Enters while pressed and restores on release/interruption.                                                                                                                                                             |
| Selected        | Enters when the existing selected-state machinery selects the owner; restores when deselected.                                                                                                                         |
| Layer attribute | A true boolean or changed finite numeric value on the animated layer starts playback. False, missing, strings and other types stop and restore. Initial true starts at mount; initial numeric values wait for an edge. |

Input triggers use the layer's native button or nearest ancestor button. **Nearest parent button** keeps decorative content from becoming a separate input target. Explicit class choices are respected; missing input owners report a conversion error. Disabled, inactive or hidden owners cannot start a chain. The attribute is a simple local key, not an arbitrary Instance path or gameplay expression.

**Restart chain** accepts a new trigger immediately; **Finish current chain** ignores retriggers while playing. Extra repeats add complete cycles; Return each cycle adds a reverse leg to every cycle. Hold final pose retains the final sampled pose until the next trigger, interruption or teardown; Restore authored pose settles at completion. State exit and visibility loss always restore. Reduced motion advances status/time and retains authored visuals while actions remain functional.

## Native runtime and property ownership

JSON import, vanilla Luau, React Lua, Fusion, roblox-ts JSX and model exports carry the same bounded chain settings and trusted generated runtime. Packages contain data; no expressions, script source, remote calls or package code evaluation are accepted. A ScreenGui runtime exposes `playKeyframes(id)`, `stopKeyframes(id)` and, for deterministic tests, `stepKeyframes(dt)` on its mount controller. Actions also use `activate(id)`. Normal Play uses one shared Heartbeat for all chains; deterministic mounts use `{manualKeyframes=true, manualMotion=true}`. Runtime status is inspectable through `FramebridgeKeyframeStatus`, `FramebridgeKeyframeTime` and `FramebridgeKeyframeIteration` on each animated layer.

Spatial chains reserve a native **Motion slot** around the animated object. Siblings keep their layout positions while its native Position, Rotation and UIScale change. The existing reservation sizing supports Hug content, text wrapping, fill/flex cells, grid reflow and native size/aspect constraints. Opacity-only chains need no reservation. The Figma layer list folds reservations into the authored layer, shows its authored geometry, and selects that layer when the reservation is clicked in the preview. Authored transparency is multiplied across descendants, with CanvasGroup applying its group fade once. Owned motion and particle helpers are excluded from the authored opacity scan. Opacity values clamp to native transparency limits; native UDim offsets round movement to the nearest pixel.

A chain owns its object's Position, Rotation and UIScale and its subtree opacity while running. Validation rejects a same-layer motion preset, advanced control or state artwork, and rejects nested chains/presets with competing subtree writers. Action/panel roles, tabs and live text may coexist when they do not own those properties. Native prompt hold-progress layers reject keyframes because the prompt runtime owns their progress geometry. Runtime cleanup restores authored geometry and opacity, preserves later application property edits, disconnects subscriptions and removes only generated helpers. Safe updates preserve existing objects, custom scripts and listeners as slots are added, changed or removed. Application content attached directly to a removed slot and an edited generated runtime retain the normal protective update failure.

Bounds: 2–32 strictly ordered frames starting at zero, at least .01 seconds apart, up to 120 seconds per leg; ±2000 pixels, .1–4 scale, ±3600 degrees and 0–4 opacity; 0–20 extra repeats; at most 256 chains per screen. Each Heartbeat step caps at .25 seconds, so a long suspended frame cannot jump an entire chain. The local timeline pauses when its document is hidden.
